# 風格圖鑑 100 · 100 Visual Styles（暫時審查網站）

開啟 `index.html` 即可瀏覽（純靜態，無需建置）。

## 第一階段流程
1. 100 個風格、10 大分類，中英對照介紹（歷史背景／視覺特徵／使用情境／常見場域／代表人物）— `data/part1-5.js`
2. 每個風格附 Pinterest 搜尋詞與連結，6 個參考圖欄位（貼圖片網址或放檔案於 `images/reference/<id>-1..6.jpg`）
3. 審查：勾選「選定」、設定狀態與備註；「匯出審查 JSON」可回傳／備份
4. ChatGPT 生圖：每個風格自動產生 6 則系列提示詞（全書共用 6 個主題，可在「系列主題設定」修改）
5. 生成結果放 `images/generated/<id>-1..6.png` 或貼網址即自動顯示
